¿Qué es el context window?
¡Buena pregunta! El context window es la "memoria de trabajo" de un modelo de IA — la cantidad de texto que puede considerar al mismo tiempo. Imaginaló como una mesa: todo lo que entra a esa mesa está "activo" para el modelo.
